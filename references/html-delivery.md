# HTML 与交付规范

## 默认交付

未指定交付要求且材料没有实质疑问时，直接在对话中交付完整文字报告，同时保存同名 Markdown 和 HTML，不先询问格式。对话正文不能被摘要或链接替代，HTML也必须保留完整正文。用户明确指定格式、展示方式、先审阅或不归档时遵从其要求。

三种交付物的范围不代表执行顺序。默认按 [交付流水线](delivery-workflow.md) 先完成并打开MD正文，让用户阅读，再生成HTML、校验和归档，自动打开最终HTML阅读版，最后在对话中展示全文及链接。不在侧栏打开之前运行HTML构建或归档，不为了预览额外生成另一份报告。

PDF、PNG 是可选衍生文件。默认只保留 HTML 内的导出按钮，不预先生成或交付独立 PDF、PNG，也不为默认报告运行可选导出检查。只有用户明确要求时才生成对应成品并验证。状态文件属于运行档案，不作为额外报告格式交付。

规范/指南同样可以用此生成器。视觉版本2.0.0，沿用用户确认的高级编辑式阅读标准，同时保留家庭会议的圆桌品牌插画。每场周报只交付一份完整报告，不再拆分会议纪要与双镜头分析。

## 阅读版视觉

页面只使用三类底色：暖白纸面、浅石色分组、深墨蓝开合。二级章节保持开放纸面；三级分组统一进入浅石色容器；四级具体议题进入纯白内层。深墨蓝只用于阅读提要、家长阅读分界或页尾收束；暖橙只用于编号、极细边框、竖线和少量关键文字，不作为大面积背景。禁止浅红、浅蓝大色块，禁止同类容器嵌套；嵌套引用必须透明，仅保留暖橙细竖线。

## 层次与字号

只用一个一级标题；二级主章节、三级分组、四级具体议题，不跳级、不为好看删减原话和限定条件。每段一意，事实/推测/建议分开；引用只放真实原话或清楚标注的示范。表格用于平行字段、行动与状态，不把长篇心理分析硬塞表格。手机表格按行变为带字段名的卡片；打印与长图保持表格结构，所有内容保留。链接不使用下划线，通过颜色、字重与外链箭头识别。

正文桌面17px、手机16px、行高约1.9；辅助11–13px；封面桌面38px/手机27–32px、章标题27px/25px，标题字重700。打印正文11pt，不为了少几页缩成难读小字。标题跟随下文，建议引导句与引用不孤立；长表允许自然分页与重复表头。

署名默认只在底部一次（用户可修改或移除，许可声明仍须保留）：**作者：阿昌 丨 公众号：阿昌正传**。居中、小号、浅灰棕、上方细线与留白，封面不署名；在PDF/PNG完整保留。顶部仅有PDF与PNG按钮，不放静态导出说明。保留侧边/手机横向目录、阅读进度和原稿下载。

## 构建

```text
python scripts/build_report_html.py path/report.md --audience parent
```

parent=含纪要和家长分析的一体化周报（默认），family=另行提取的家庭共读附件，guide=说明/规范。audience只控制标识，不自动删除敏感段落；必须先审查正文。`--headline`只用忠实摘要，不改嵌入原稿，不编故事。`--output`可指定HTML位置。

构建器仅Python标准库，HTML内嵌全部CSS/JS/插画/Markdown；双击离线可用，无CDN、远程字体、上传、追踪或在线截图服务。源数据经过安全Markdown渲染，原生HTML作为文字显示，拒绝危险链接；不要直接执行输入里的脚本。

## 导出

PDF按钮打开浏览器打印，用户选择另存为PDF；不能承诺自动无对话下载。打印A4、背景保留、工具栏隐藏、文字可搜索、链接保留。PNG按900 CSS px宽、2倍分辨率，内部小画布逐条绘制后编码成**一个完整PNG**，不拆成两张、不截断、不降低正文可读性。原生CompressionStream不可用时使用本地zlib存储块回退。失败明确报错并允许重试，不伪报成功。

工具栏不进入导出；PNG按钮生成中禁用、显示进度，结束释放临时iframe，允许重复导出。所有报告含完整MD base64，下载须与文件字节一致，不能另存一个视觉处理过的缩水稿。

## 分级验证

验收跟随实际交付范围，不把可选导出检查强加给默认报告：

1. **每次默认交付：** 核对对话报告与MD正文完整一致；检查HTML编号、内嵌原稿字节与哈希、完整资源和基本结构，保留表格、原话、匿名边界与来源链接。MD+HTML均保存成功才算默认文件交付完成；缺失时说明待补。
2. **模板与渲染器未变化的日常报告：** 快速结构和内容检查即可，不重复所有视口、长图和打印回归。新发现的显示问题仍要修复，复查受影响的内容与呈现，不用“快速”掩盖已知缺陷。
3. **模板、样式、生成器或导出代码变化：** 用代表性短、长报告按影响范围进行浏览器回归，检查桌面、320/390/430px手机和横屏、目录、原稿下载、唯一署名、完整正文、横向溢出和离线运行；相关打印或导出变化再查PDF、PNG。测试文件留在`.qa/`，不自动作为用户成品。
4. **明确要求独立PNG：** 实际导出一次，确认只生成一张完整图片，核对首尾、中间接缝、宽高和署名。编码器变更时再测试超长报告、回退和重复导出。
5. **明确要求独立PDF：** 实际生成PDF，检查全文可提取、分页、标题和正文完整性，无截断或空白溢出页；按钮文字存在不等于成品已验证。
6. **补格式或纯排版修订：** 只更新约定文件，不重做分析、不重复计数，不因本地存在旧PDF/PNG就自动重建；旧导出应标明历史版本，避免被当作最新结果。

`python -m unittest discover -s scripts -p "test_*.py"` 测日历、重复与构建不变量；`node scripts/test_png_encoder.cjs` 测PNG像素、CRC、长图及回退。仅相关实现变更或新发现问题时运行对应测试，不把全套测试设为每篇新报告的前置步骤。

资源：本地Marked17.0.5和html2canvas1.4.1，保留vendor许可证；原创圆桌SVG和单PNG编码器随包。内容引擎与视觉解耦，旧报告无H3/H4也应完整显示。临时QA输出放独立`.qa`，不混入家庭成长档案。
