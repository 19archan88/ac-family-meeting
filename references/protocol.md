# 运行与记忆协议

## 时间与编号

采用原始材料明确日期，其次用户提供日期；缺少日期则提出有依据的推断并请确认，未确认前不出正式报告。用户明确纠正原材料时采用校正并记载依据。提交时间、文件时间、当前日期都不是会议日期。用户明确授权按推断继续时标注“推定日期”，保留不确定性。

标题按源文件使用“YYYY年第N次”。以实际召开次数计数，默认年度内连续编号，并保存不随重渲染改变的 meeting_id。已有家庭连续届数体系时保留其口径，不擅自重置或混算；记录 numbering_scope。默认 `FM-YYYY-NNN-YYYY-MM-DD`。同日多场会议必须另有届数/记录证据。跨年重置年度届数不表示家庭历史归零。

材料和上次摘要存在跳号、倒序、同日期疑似重复、同一来源摘要时暂停正式报告，给出差异并请用户确认是补录、修订、另一场还是遗漏。确认修订更新原 meeting_id；确认补录重新核对月内次数和受影响聚合。单纯重新排版无需重问、不增会议。无历史时明确“本次为可见档案起点”，请确认届数或允许暂记“届数待确认”，不擅称家庭首次开会。本月第N次必须来自已确认完整月内记录；历史不齐时另列“可见记录X次”，不能冒充准确月序。

会议日期归属自然月，不按周五锚定。学期使用私有家庭配置中已确认的日期范围，支持不同校历和多学期制。未配置或未覆盖时请求补充，不把未知区间视为暑假。原两学期规则仅在家庭确认采用后适用。

年报按自然年1–12月。以下“两份学期”和“8月”适用于已确认的原两学期制；自定义校历时改为当年实际学期数与假期范围，逐期核对。源文件要求全年月摘要及两份学期全文；两份学期未必覆盖自然年全部月份：列出两份实际学期范围，再依据月摘要补足年内月份与8月，排除学期中年外事件，不把跨年学期整份加总。缺某学期/月份必须披露，补齐或经用户允许生成“不完整材料版”。两份学期不是证明年度完整的条件。

## 交付范围与确认

遵循 SKILL.md 的“交付决策”，适用于周、月、学期和年度报告。未指定要求且材料无实质疑问时，直接交付对话全文、同名 Markdown 和 HTML，不先询问格式。用户指定“只要文字”“只要文件”“先审阅”或“不归档”时优先遵从；仅影响分析可靠性或归档的关键疑问需要集中澄清，不因可选导出缺失而暂停默认交付。

默认顺序为：内容核对完成 → 保存并在侧栏打开完整MD供阅读 → 告知继续生成HTML与归档 → 自动完成所需文件检查和归档 → 自动打开最终HTML → 最终对话全文及文件链接。先打开正文不是“先审阅”模式，不增加确认；如果用户明确要求先审阅，则仍在批准前不生成正式文件、不更新状态。MD或最终HTML的打开请求排队或失败时，给对应文件链接并如实说明，不轮询、不谎报已打开。最终HTML打开操作在最终答复前完成。执行与增量格式见 [交付流水线](delivery-workflow.md)。

PDF、PNG 默认仅作为 HTML 的按需导出能力，用户明确要求独立文件时才生成和交付。模板变更所需的导出回归属于测试，不将其结果自动放入正式档案或作为额外交付物。

## 触发与提醒

- 原始会议提交触发一份一体化周报。用户可指定只修订纪要区或分析区，但交付时仍重建同一份报告，并保留另一部分的既有有效内容。
- 月报：用户请求；或原稿明确本次为当月最后一次自动触发。每次周报后检查是否还可能开会，不确定提示“本月已有X次会议记录，如本月会议已全部结束，可发送‘生成月报’触发月度分析”。X仅指可见记录数。
- 学期报：明确请求，或明确本学期最后一次自动触发。按家庭配置的学期提醒月份在本任务被调用时各提醒一次。
- 年报：明确请求，或明确本年最后一次自动触发；12月已确认最后一份周报后提醒一次。多个周期同时符合时，先完成周报再按依赖顺序处理被触发周期，缺材料停在对应级别，不虚构。
- 日历并不保证本期最后一次。此 skill 不自带后台调度，未被调用不会主动提醒；仅用户另行要求时建立真实自动化，不隐式创建。reminders记录已提醒期键，重渲染不重复提示。

## 数据与统计

来源标记至少包含报告/会议ID和日期，可用原始时间戳定位原话。月度每个趋势论断至少两个不同周的证据；同周两场不是两周趋势。学期/年报对照必须是真实早期与近期片段。人物消失仅表示未在提供材料出现，不推定关系结束。

发言占比说明按字符/词数估算或真实录音时长，不能混淆；无可靠说话人/录音不得报精确时长占比。打断、沉默和情绪强度无明确转写/音视频证据就不量化。平均时长只用已知会议；出席率以已知出席记录为分母，另报缺失；总会议数只数实际独立 meeting_id，不数报告文件或导出格式。

行动有稳定 action_id，区分：**会议决议/当事人自我承诺**、**对他人期待**、**对外界期待**、**AI父母建议**。期待未被对方接受不变成承诺；AI建议不自动进入纪要“已达成”事项。AI清单另列是否采纳，未确认不按未做追责。表格保留源要求字段，可追加ID、来源、截止/评估日期、证据。

执行状态：完成、部分、未做、未知；处理：继续、调整、取消；未记载=未知，不补成未做。统计按到评估期且未取消的已接受事项，完成率=完成数/有明确执行状态的事项数；部分完成单列，不擅自折算；另报未知数、取消数、未到期数、可核实覆盖率。未采纳的AI建议另列，不能暗减分母或称全清单完成率。分母为0则“不可计算”。照顾者整体及每位实际家庭成员可分列，年度必须按实际成员分列。同一延续行动跨周复核不重复加总；拆分/替换行动保留关联。

“低于50%”只在可计算的执行率上应用；首先检视过载或不够具体，不归责。议题解决率=有明确解决/试行达成且复核认可的议题数/可评估议题数，试行中、未知分列。孩子行为类议题当月超过2次按实际议题出现记录计数，标来源，不据此诊断孩子。

健康仪表盘是家庭过程观察，非量表或对孩子打分。无证据写“资料不足/未评估”，不能强选绿黄红。安全感仅为可能解释，分享“刺”更少也可能受议题、疲劳或材料缺失影响。红色项附具体证据、可能原因、修复建议。连续两个月/跨学期的专业支持建议保留源规则；明显紧迫安全风险不等待周期到期。

三阶段源文件未给判定阈值，不伪造标准。可作说明性观察：点火期关注愿意参与、仪式能启动；深化期关注真实分享、多方协商；闭环期关注行动复核与调整。依据实际证据给维持/升档/降档建议，证据不足则“不足以定位”，阶段不是评级阶梯。

## 事实与专业审计

双镜头报告必须保留“会议内容审计评估报告”。按实际主题选恰当专业视角，逐项列原话/时间、事实或逻辑问题、校准说明、父母可用回应。不要冒充拥有专家资格。需要核实时查官方机构、原始研究或权威专业指南，附直接链接及核查日期；无法联网则标“待核实”，不捏造来源或硬下结论。建议与事实纠错分开。不把各方偏好、孩子幻想或不同价值选择当事实错误。

## 隐私与共读

无须再次确认常规匿名化；孩子采用用户指定代号，其他人按角色/同学A等替换，保留指代一致，无法分辨标存疑。名字相近不足以合并人物。只用角色称谓的报告无需强称“已匿名化所有细节”。对删除范围不明确的敏感片段先排除并问边界，不引用片段复述追问。文件名、摘要和导出也遵守。

纪要金句、月度相册、学期纪念册、年度奖词面向孩子，语言随实际年龄发展，而非永远固定6岁。父母镜头、敏感关系推测、专业干预提示为家长私读；混合报告默认家长版，家庭共读需提取合适章节独立文件。分享行为由用户另行决定，不能自动上传。

## 文件与状态

所有家庭数据放用户指定目录/档案，不写 skill。可复用文件名：

- 周报：`FM-YYYY-NNN-YYYY-MM-DD.md/.html`；同名 PDF/PNG 仅在用户明确要求时生成，不再使用 `-minutes`、`-analysis` 拆分文件。
- 月报：`FM-M-YYYY-MM.md/.html`。
- 学期：`FM-S-YYYY-YYYY-upper.md/.html` 或 `FM-S-YYYY-lower.md/.html`。
- 年报：`FM-Y-YYYY.md/.html`；共读附件后缀 `-family`。

先备份被修订报告；纯排版修改只重建约定范围内的呈现文件，不改MD分析、状态、行动或统计。旧PDF/PNG存在不代表本次自动需要重建；未更新的旧导出保留为历史版本并说明，避免混充当前成品。Markdown内嵌与下载原稿完全一致；只补格式不新增会议、行动或信号。

默认在对话展示完整报告，并在 MD+HTML 均成功落盘后更新正式状态（临时文件写入后原子替换）。用户改变交付或归档范围时按约定判断；只交审阅稿时不生成正式文件、不标记已分析、不更新正式状态，明确“不归档”时也不更新。约定格式有缺失时如实说明待补，不伪称完整交付；可选PDF/PNG未生成不算缺失。状态JSON属于运行档案，只简要说明真实保存结果，不作为常规报告成品反复展示。一体化周报末尾只有一个归档摘要，共享meeting_id/届数/日期/月序；共读事实与家长私读信号用不同字段标注。

正文提前可读时，归档摘要可写“正文已完成；文件与归档状态见交付说明”，最终说明再报告实际结果，避免为了变更状态重写整篇正文。通用脚本接受已核对的状态增量，保留旧文件备份、稳定ID与来源，验证成功再提交。补录默认追加历史；有较新会议证据时禁止用旧日期覆盖行动或信号的当前字段。状态基准哈希变化须重新读取并合并，不盲目覆盖。脚本的成功不代替内容、隐私或来源真实性审查。

状态最小结构为 JSON 对象，包含 `schema_version`、`prompt_version`、`numbering_scope`、`meetings`、`reports`、`actions`、`signals`、`reminders`。所有列表初始可为空，但没有实际会议输入本次不新建运行状态。meeting记录包含 id、date、number、source_sha256、month_index、status、单一 `report` 路径、revision与date_basis；reports中每场会议只有一条 `weekly_combined` 记录，另含覆盖范围、输入ID、版本与缺失项；actions与signals均有来源、状态、确认依据和更新记录；reminders存已提示的期键。未知字段用null或明确unknown，不硬填空串或示例事实。

无状态但有旧报告：先按可见证据重建索引并披露缺失；不得从源规范创建示例家庭历史。禁止把报告生成本身记成行动已完成或信号已解除。修订记录保留原版和受影响聚合的需重建标记。没有云接口只交本地结果，不编造存档成功。

## 数量约束与证据补取

源要求的金句/高光/片段/行动/奖项数量与篇幅是输出目标，真实证据优先：不够就保留栏目、注明实际数量和缺口，不编凑。三人家庭年度各至少两项与5–8项同时成立时采用6–8项；其他人数按逐人平等覆盖原则调整，详见家庭初始化；奖词须有真实事例，无证据先补材料。学期/年度成长叙事不低于7:3不等于必须捏造积极转折。

月度相册需要回查周纪要金句和原话，月报基本输入中的行动表不足以支持相册。学期/年报对照、奖词、年度精确统计需要时回查对应月报全文、周报、原稿及行动台账；摘要没有的证据不能靠推断补齐。明确来源层级和缺失范围。

## 聚合材料不足与删除区间

所有月/学期/年度聚合均先检查必需输入与覆盖范围；自动触发不是材料齐全的证明。缺材料先列出缺口并停在对应级别；用户明确接受时可交“不完整材料版”，保留未知与缺失标记。只有一个可见周不能生成月度趋势，不把有限快照包装成完整月报。

“这段不录”至明确恢复标记之间全部排除；恢复仅对后续内容生效。不得从排除区间间接提炼观察信号、行动、审计或摘要。删段边界清楚不必再问；边界不明先排除并仅询问范围。
